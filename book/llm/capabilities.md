# Advanced capabilities

## In-context learning

Examples supplied in the prompt can define a task without updating parameters.

## Conversation and instruction following

Multi-turn state and explicit instructions enable iterative musical exploration.

## Reasoning

Structured intermediate steps can help with multi-constraint tasks, although
plausible reasoning is not evidence of perceptual grounding.

## Tool calling

An LLM can choose and parameterize external tools such as search engines, audio
analysis functions, digital audio workstation controls, or notation renderers.
