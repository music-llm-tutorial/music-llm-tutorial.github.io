# Feedback and assessment

Perceptual analysis answers *what happened* in a performance. Feedback and assessment answer *what the performer should do next*. The language model sits between the two: it takes score-linked measurements (timing deviations, pitch errors, dynamic mismatches, technique signals) and turns them into explanations a learner or teacher can act on.

This section covers the translation in three steps: how measurements become natural-language feedback; the open data problems (taxonomy, acquisition, alignment, description) that limit what such systems can learn from imperfect performance; and a worked example that fine-tunes an audio-language model into a performance coach.
