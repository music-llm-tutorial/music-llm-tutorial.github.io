# Feedback and assessment

Perceptual analysis answers *what happened* in a performance. Feedback and assessment answer *what the performer should do next*. The language model sits between these two: it takes score-linked measurements — timing deviations, pitch errors, dynamic mismatches, technique signals — and turns them into explanations that a learner or teacher can act on.

This section covers that translation in three steps: how measurements become natural-language feedback; how deployed systems put that loop into practice apps and teacher tools; and the open data problems — taxonomy, acquisition, alignment, description — that still limit what those systems can learn from imperfect performance.
