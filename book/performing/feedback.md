# Feedback and assessment

Perceptual analysis answers *what happened* in a performance in metrics. Feedback and assessment answer *how should we communicate this to performer and what they should do next*. The language model sits between the two: it takes score-linked measurements (timing deviations, pitch errors, dynamic mismatches, technique signals) and turns them into explanations a learner or teacher can act on.

This section covers the translation in three steps: how measurements become natural-language feedback; the open data problems (taxonomy, acquisition, alignment, description) that limit the bridge between audio and language from imperfect performance; and a demo that fine-tunes an audio-language model into a performance coach.
