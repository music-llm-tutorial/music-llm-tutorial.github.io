# Architectures and modalities

<p style="color: #6b7280; font-size: 0.9rem;">Presenter: Zachary Novack</p>

A common large music-language model combines a modality encoder, an adapter or
projector, and a language-model decoder.

| Input | Strength | Central challenge |
|---|---|---|
| Audio | Captures timbre and performance | Long, high-rate sequences |
| Score image | Preserves visual notation | Layout and symbol grounding |
| Symbolic text | Discrete and editable | Representation and tokenization choices |
| Text metadata | Abundant and searchable | Weak or noisy musical grounding |
