# Applications for listeners

## Annotation and description

LLMs can turn multimodal evidence into flexible descriptions tailored to a
listener's vocabulary and intent.

## Conversational retrieval and recommendation

A dialogue can refine constraints over several turns, while tool calls retrieve
and rank candidates from a real catalog.
