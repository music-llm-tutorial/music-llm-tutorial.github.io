# Evaluating LLMs

Evaluation should separate language quality from musical correctness and task
utility. A useful evaluation card records:

- task and target user;
- input modalities and required evidence;
- automatic metrics and human judgments;
- contamination and memorization risks;
- uncertainty, failure modes, and subgroup analysis.

**Discussion:** Can a fluent answer score highly while ignoring the audio? Design
a control condition that would expose this behavior.
