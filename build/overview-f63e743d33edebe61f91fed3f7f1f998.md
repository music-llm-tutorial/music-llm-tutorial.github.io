# Motivation and roadmap

Large language models are no longer confined to text. They increasingly act as
a shared interface across audio, symbolic music, scores, and metadata. This
tutorial asks a practical question: **which LLM capabilities matter for music,
and how can we deliberately use them?**

## Learning goals

By the end of the tutorial, participants should be able to:

1. connect autoregressive modeling and post-training to modern LLM behavior;
2. compare architectures for audio, score-image, symbolic, and text inputs;
3. select capabilities such as instruction following, reasoning, or tool use for a musical task;
4. identify suitable benchmarks and limitations for a music-language system.
